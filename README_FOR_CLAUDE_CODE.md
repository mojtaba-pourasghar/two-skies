# دو آسمان (Two Skies) — بستهٔ تحویل به Claude Code

بازی: پلتفرمر معمایی پیکسل‌آرت دو شخصیتی (ایلارا و کایرو) برای موبایل، ساخت با Godot 4.5/GDScript.
نسخهٔ ۱ = فقط فصل ۱ مراحل ۱ تا ۳، بازار ایران (Adivery، کافه‌بازار/Poolakey، بدون سرور، قیمت به تومان).

## ترتیب خواندن
1. docs/01_main_design_and_screenplay_ch1-8.md — مصوبات طراحی، داستان هشت فصل، فصل ۱ کامل، طراحی مراحل فصل ۱
2. docs/02_godot_spec.md — مشخصات فنی کامل (فیزیک، ماشین حالت، ابزارها، قالب JSON مرحله، ذخیره، UI، صدا، تبلیغات، §26 نقشه‌های تولیدشده)
3. docs/05_release_v1_plan.md — محدودهٔ نسخهٔ ۱ و انتشار
4. docs/screenplay/ch2..ch8.md — فیلم‌نامهٔ کامل فصل ۲ تا ۸ (نما، افکت، صدا، دیالوگ، انتخاب‌ها)
5. docs/03_levels_ch2-8.md — طراحی مراحل فصل ۲ تا ۸
6. docs/04_art_and_sound_bible.md — پالت یکپارچه، قالب صحنه، فهرست دارایی‌ها
7. docs/06_side_games.md و docs/07_letters_and_survivors.md

## نقشه‌های کاشی
- tilemaps/ch{N}_l{M}.json — ۶۶ مرحلهٔ فصل ۲ تا ۸ (۳۹۱ اتاق، هر اتاق ۳۰×۱۷)
- tilemaps/all_rooms.txt — نمای متنی همهٔ اتاق‌ها
- tools/generate_rooms.py — مولّد و اعتبارسنج (BFS هوایی: پرش ۴ بالا/۶ افقی، چاله کشنده، قلاب برد ۶، در/کلید)
- فصل ۱ نقشه‌هایش در docs/02_godot_spec.md بخش ۱۱ است.
- این‌ها اسکلت هندسی‌اند؛ باید در Godot با test_solvable.gd سنجیده و در بازی‌تست دستی صیقل شوند.
  محدودیت‌ها: مراحل ترکیبی فعلاً اتاق جانبی با در/کلید به‌جای سوییچ دو دنیا؛ قلاب و EMP تقریبی.

## نکته
متن‌ها فارسی راست‌به‌چپ‌اند؛ کلیدهای رشته به شکل c{فصل}_l{مرحله}_{nn} در strings_fa.json.
بخش‌های release/sidegames/letters از روی ساختار سند به متن تبدیل شده‌اند؛ اگر جدولی ناقص دیدید به سند اصلی مراجعه کنید.
