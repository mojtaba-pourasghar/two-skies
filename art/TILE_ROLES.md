# نقش و محل استفادهٔ کاشی‌ها (نام‌گذاری مدیر پروژه، ۱۴۰۵/۰۸/۱۴)
نام هر کاشی در `names.json` کنار آن است (`art_drop/tiles_side_ch1/<صحنه>/` و `art_drop/tiles_ch1_v2/<صحنه>/`)؛ فایل‌ها همان شماره‌ای می‌مانند. `kind` تعیین می‌کند چه برخوردی بدهی.

| `kind` | معنی در بازی |
|---|---|
| `solid` | سطح جامد (برخورد کامل) |
| `oneway` | پلتفرم یک‌طرفه (از پایین رد می‌شود) |
| `background` | پس‌زمینهٔ بدون برخورد |
| `decor` | تزئینی بدون برخورد |
| `foreground` | جلوی شخصیت (لایهٔ بالا) |
| `door` | در/گذرگاه |
| `slope` | پله/شیب |
| `ladder` | نردبان (جای‌نگهدار؛ مکانیک نردبان در نسخهٔ ۱ نیست) |
| `walkable` | کف قابل راه‌رفتن |
| `walkable_decor` | کف قابل راه‌رفتن با نقش (تله/هک/دریچه را روی آن می‌گذار) |
| `wall` | دیوار/مانع با Y-sort |
| `passage` | ورودی/طاق قابل عبور |

## کجا استفاده شود
| حالت | صحنهٔ کاشی | مرحله‌ها |
|---|---|---|
| side | house | مرحلهٔ ۱ و اتاق‌های داخلی |
| side | street | مراحل ۳ و ۷ (و ۸) |
| side | basement | مرحلهٔ ۵ |
| topdown | house | اتاق مخفی ایلارا |
| topdown | street | مرحلهٔ ۲ |
| topdown | basement | مراحل ۴ و ۶ |

قواعد:
- `side`: `ground_*`/`ceiling_*`/`curb`/`crate` = TileMap با برخورد؛ `platform_*` = یک‌طرفه؛ `wall_*`/`pillar`/`corner` = لایهٔ پس‌زمینهٔ نزدیک (بدون برخورد)؛ `railing`/`window`/`door` = تزئین؛ `ladder` در نسخهٔ ۱ فقط تزئین است.
- `topdown`: `floor_*`/`asphalt_*`/`rug_*` = کف؛ `grate_*`/`manhole`/`hatch` = کف با نقش (هازارد یا هک را روی آن بگذار، خود کاشی برخورد ندارد)؛ `wall_*`/`cabinet_*` = مانع با Y-sort؛ `wall_archway_lit` = ورودی.
- اگر کاشی لازم نیست‌ای که نیست (مثلاً سقف در `topdown`)، از `art/PRODUCTION_LIST.md` درخواست تولید بده؛ کاشی را از کد نساز.
