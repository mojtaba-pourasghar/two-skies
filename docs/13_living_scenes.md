# سند ۱۳ — صحنهٔ زنده (Living Scenes) — هیچ پس‌زمینهٔ مرده‌ای نداریم
دستور کاربر (۱۴۰۵/۰۸/۱۶): پس‌زمینه‌ها، افکت‌ها و همه‌چیز در کلیپ مرجع **زنده** است؛ بک ثابت مرده قابل‌قبول نیست. فقط **ساختار** (حرکت، لایه، نور، ذره) تقلید می‌شود؛ هیچ محتوای کلیپ کپی نمی‌شود (قانون ۵).

> **قرارداد موتور و عددها:** `docs/13_camera_and_living_world.md`. سطح‌های
> زوم، زمان گذار، ناحیهٔ بی‌اثر دوربین و قالب دادهٔ `ambient` آنجاست.


## قاعدهٔ بودجهٔ زندگی (هر اتاق/ناحیه، آزمون‌پذیر)
هر اتاق باید حداقل این‌ها را داشته باشد؛ بدون آن «تمام» نیست:
1. **≥۳ منبع حرکت محیطی همزمان** (مثلاً شعلهٔ شمع + پردهٔ تکان‌خورنده + ذرهٔ گرد).
2. **نور زنده:** هر نور نقاشی‌شده یک overlay نبض/سوسو دارد (۲ هرتز، دامنهٔ ±۱۵٪، فازهای تصادفی).
3. **جوّ:** لایهٔ مه/دود در حال رانش آرام (۲ لایه با سرعت متفاوت، Add/Mix).
4. **ذره:** گرد/اخگر/خاکستر/جرقه طبق نوع اتاق (`overlays/particles`).
5. **جان‌دادن به شخصیت‌ها:** idle تنفس (حتی ایستاده)، NPC با idle حلقه‌ای، سایهٔ پویا زیر پا.
6. **دوربین زنده:** هیچ‌وقت کاملاً ثابت نیست — دنبال‌کردن نرم با اینرسی، لرزش ریز (±۱px) هنگام رویداد، گذار نور هنگام ورود به در.
7. **واکنش:** وقتی بازیکن رد می‌شود چیزی واکنش نشان دهد (علف/برگ تکان، گرد برخیزد، سایه کشیده شود).

## تکنیک‌ها (کد؛ روی همان نقاشی، بدون بازنقاشی)
| اثر | روش |
|---|---|
| آب/مه/بخار | shader با نقشهٔ جابه‌جایی (displacement) و ماسک؛ UV scroll دو لایه |
| برگ/پرده/پرچم | shader تکان با ماسک وزن‌دار (ریشه ثابت، نوک آزاد)؛ ماسک از روی تصویر |
| آتش/شعله/نئون | اسپرایت حلقه‌ای + overlay نور Add با نویز؛ نئون سوسوی متناوب |
| پارالاکس | پس‌زمینهٔ خارجی چندلایه (آسمان/دور/میانه/پیش‌زمینه)؛ برای اتاق‌های داخلی لایهٔ پیش‌زمینه occluder با حرکت مختلف |
| عمق میدان | شیدر تاری ملایم روی پیش‌زمینه/دورنما |
| سایهٔ پویا | سایهٔ بیضی زیر هر بازیگر + نور نقطه‌ای که بازیگر را از جهت لامپ روشن می‌کند |
| گذار | محو + تغییر نور 0.3ث |
> برای جداکردن لایهٔ عمق از تصویر نقاشی‌شده، ابزار Canva «separate-image-layers» را می‌توان روی صحنه‌های خارجی امتحان کرد (اختیاری؛ نتیجه باید بازبینی شود).

## هنر انیمیشنی لازم (حلقه‌ها)
- دستهٔ ۲۰: شعله/شمع/لامپ، پرده/پارچه، دود/بخار، چکه، گرد (فریم‌های حلقه‌ای روی مگنتا).
- دستهٔ ۲۱: برگ/گیاه تکان، پروانه/پشه/پهپاد کوچک idle، سوسو نئون، موج آب/لکهٔ نور آب.
- NPC‌ها و دشمن: idle حلقه‌ای (۴–۶ فریم) از برگه‌های موجود.
هر ردیف REQ در `comms/ART_REQUESTS.md` بیاید.

## آزمون پذیرش (Claude Code)
ضبط ۱۰ ثانیه از هر اتاق → کاربر تأیید «زنده است» می‌دهد. سنجهٔ خودکار: میانگین اختلاف فریم‌به‌فریم پس‌زمینه > ε (نه ثابت) و حداقل ۳ node متحرک در `LivingLayer` گروه.
