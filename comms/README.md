# کانال ارتباط بین مدیر پروژه/هنر (Claude دستیار) و Claude Code

دو نشست مستقیماً با هم حرف نمی‌زنند؛ این پوشه از طریق git پل است. هر دو طرف **هر بار که شروع به کار می‌کنند و قبل از هر کامیت** `git pull` و این پوشه را می‌خوانند.

| فایل | نویسنده | کاربرد |
|---|---|---|
| `ART_REQUESTS.md` | Claude Code | هر جا تصویر/طرح/اتاق/اسپرایت/افکت ندارد، یک ردیف اضافه کند (قالب پایین) |
| `ART_REPLIES.md` | مدیر هنر | پاسخ: وضعیت (در حال تولید / تحویل‌شده با مسیر `art_drop/...` / رد با دلیل) |
| `CODE_STATUS.md` | Claude Code | وضعیت کد: آخرین گام، تست، پرسش‌های باز، چیزی که منتظر هنر است |
| `DECISION_QUEUE.md` | هر دو | تناقض‌ها/تصمیم‌هایی که کاربر باید بگیرد |

## قالب درخواست (ART_REQUESTS.md)
```
### REQ-<شماره> — <عنوان>
- اتاق/ناحیه: R1x / S2x / C1…  | دوربین: topdown (همه‌جا؛ D-ART-32)
- چه می‌خواهم: <توضیح یک‌خطی>
- ابعاد/مقیاس: <مثلاً ۱۲۸۰×۷۲۰ یا ۶۴×۶۴ ، فریم‌ها>
- اولویت: P0 (کد بلوکه) / P1 / P2
- وضعیت: open
```
## قوانین
- همه‌چیز **سه‌چهارم (topdown)** است؛ `side` و `camera_zone` لغو است (D-ART-32).
- Claude Code تصویر نمی‌سازد و به‌جایش هنر کدساخته را فقط در `art/drafts/` به‌عنوان جانگهدار می‌گذارد.
- مدیر هنر کد بازی نمی‌نویسد.
- هیچ توکن/کلیدی در این پوشه نیاید.
