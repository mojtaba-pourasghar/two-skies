# معماری کاشی‌محور ناحیه (بایگانی، نه حذف)

این‌ها از دوره‌ای مانده‌اند که ناحیه از **کاشی تکرارشونده** ساخته می‌شد.
سند ۱۱ (D-ART-30) و سند ۱۲ §۷ این را کنار گذاشتند: هر اتاق یک **تصویر
نقاشی‌شدهٔ کامل** است و کاشی فقط «پرکردن حاشیه» می‌ماند.

دلیل صریح سند ۱۱: «اسکرین‌شات‌های MVP ناحیهٔ ۱ (کف نارنجی تکراری، بلوک‌های
ساده) از نظر کاربر قابل‌فروش نیست».

| فایل | چه بود |
|---|---|
| `area_loader.gd` | قالب JSON ناحیهٔ کاشی‌محور با لایهٔ کف/دیوار |
| `explore_area.gd` | سازندهٔ صحنه از کاشی و `roles.json` |
| `explore_game.gd` | صحنهٔ قابل‌بازی ناحیهٔ ۱ |
| `test_explore.gd` | ۳۸ سنجهٔ همان معماری |
| `ch1_a1.json` | دادهٔ ناحیهٔ ۱ کاشی‌محور |

جایگزینشان در `game/rooms/` است: اتاق نقاشی‌شده با ماسک چندضلعی.
چیزهایی که **نماندند و هنوز به‌کار می‌روند**: `explore/trap.gd`،
`explore/save_point.gd`، `explore/actor_visual.gd`.
