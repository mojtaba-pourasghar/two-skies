# قرارداد دارایی‌های هنری «دو آسمان»

این فایل قرارداد میان **کد** و **هنر** است. هنرمند فایل را با همین نام، همین
اندازه و همین ترتیب فریم جایگزین می‌کند و **هیچ کدی دست نمی‌خورد**.

> همهٔ هنر فعلی **موقت** و تولیدشده با اسکریپت است. جایگزینی‌اش کار هنرمند
> است، نه بازنویسی کد.

### شخصیت (نمای سه‌چهارم)

| فایل | اندازهٔ فریم | فریم‌ها | ترتیب |
| --- | --- | --- | --- |
| `art/sprites/td/kairo.png` | ۳۲×۴۰ | ۶ | پایین ۲، بالا ۲، پهلو ۲ (پهلو برای جهت مخالف آینه می‌شود) |

نشانهٔ مشترک هر دو شخصیت: **خط دوخت سفید یک‌پیکسلی روی روسری**.

فیروزه‌ای و کمان بذر روی پشت.

## ساختن دوباره

```bash
python3 -I tools/art_gen/cli.py list
```

```bash
python3 -I tools/art_gen/cli.py build --dry-run
```

```bash
python3 -I tools/art_gen/cli.py build --only kairo_3q
```

```bash
python3 -I tools/art_gen/cli.py cost
```

`--dry-run` هیچ فراخوانی تازه‌ای نمی‌کند: فقط از کش و از `tools/art_gen/specs/`
می‌خواند. پس می‌شود کل خط لوله را بدون خرج کردن سنجید.

## کلیدها

فقط از متغیر محیطی، هرگز در فایل: `ANTHROPIC_API_KEY`،
`CLOUDFLARE_API_TOKEN` (یا `CF_API_TOKEN`)، `CLOUDFLARE_ACCOUNT_ID`
(یا `CF_ACCOUNT_ID`). سقف هزینه با `ART_BUDGET_USD` و `ART_CF_NEURONS`.
`tools/art_gen/config.py::redact()` هر چیزی شبیه کلید را از لاگ برمی‌دارد.
