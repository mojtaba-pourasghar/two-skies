# کد حالت کناری (بایگانی، نه حذف)

D-ART-32 (دستور کاربر): **کل بازی سه‌چهارم است**، از جمله اتاق‌های چالش.
حالت `side` و `camera_zone` لغو شدند.

| فایل | چه بود |
|---|---|
| `challenge_room.gd` | اتاق چالش کناری با ورود/خروج خودکار `camera_zone` |

آنچه از آن **ماند** و به اتاق چالش سه‌چهارم منتقل می‌شود: مرگ بی‌نهایت،
ریستارت زیر ۰٫۳ ثانیه، شمارندهٔ مرگ، و چک‌پوینت ایمن.
